**В простом парсере можно увидеть**
- Понимание ООП
- Парсинг текста на предложения, слова и знаки препинания
- Классы Text, Sentence, Word, Punctuation, TextParser
- Сортировка предложений по количеству слов
- Сортировка предложений по длине
- Поиск слов заданной длины в вопросительных предложениях
- Удаление слов заданной длины, начинающихся с согласной
- Замена слов заданной длины на подстроку
- Удаление стоп-слов
- Подсчет частоты слов с номерами предложений
- Сериализация в XML
- Чтение из файла
- Работа с коллекциями List, Dictionary, SortedSet
- Использование LINQ
- Консольный ввод/вывод
